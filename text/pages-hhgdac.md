# Hitchhiker's Guide to Docs-as-Code

 
 Eine Kolumne im JavaMagazin von Ralf D. Müller und
 Dr. Gernot Starke über moderne technische Dokumentation mit dem Docs-as-Code-Ansatz.
 

 
 
 
 Kolumne
 JavaMagazin 2017-2018
 

 
 In dieser Artikelserie zeigen wir, wie man Dokumentation wie Code behandelt:
 mit denselben Werkzeugen, Prozessen und der gleichen Sorgfalt. Von den Grundlagen
 mit AsciiDoc über Build-Automatisierung bis hin zu professionellem PDF-Output.
 

 
 
 GitHub Repository
