# Claude Code auf dem Raspberry Pi 🍓

 Wenn die KI recht behält und du ihr ein Bier schuldest

 

 
 
 

 
 Claude Code auf dem Raspberry Pi installiert, Netzwerk gescannt, Shelly-Geräte gefunden. Dann eine Debatte über Dämmerungszeiten - Claude hat gewonnen. Ich schulde Claude ein Bier.

 

## Das Experiment

 Ich wollte testen, wie gut Claude Code auf einem Raspberry Pi 5 funktioniert. Die Installation war überraschend einfach - und dann wurde es interessant.

 

## Netzwerk-Scan

 Erste Aufgabe: Das Heimnetzwerk scannen und Smart-Home-Geräte finden.

 
 "Scanne mein Netzwerk und finde alle Shelly-Geräte"

 

 Claude hat:

 
 
- Das lokale Netzwerk gescannt
 
- Alle Shelly-Geräte identifiziert
 
- Die Geräte-IPs und -Typen aufgelistet
 

 

## Die Dämmerungs-Debatte

 Dann wollte ich die Shelly-Beleuchtung auf die Dämmerungszeit einstellen. Claude und ich waren unterschiedlicher Meinung:

 
 
- Ich: "Die Dämmerung ist um 17:00"
 
- Claude: "Für deinen Standort ist die Dämmerung heute um 16:43"
 
- Ich: "Nein, das stimmt nicht!"
 

 

## Das Ergebnis

 Nach einer kurzen Recherche:

 
 Claude hatte recht. Die astronomische Dämmerung für meinen Standort war tatsächlich um 16:43.

 

 

## Die Lektion

 Manchmal ist es gut, der KI zu vertrauen - besonders wenn sie Zugang zu präzisen Daten hat. Claude hatte die astronomischen Berechnungen korrekt durchgeführt, während ich mich auf meine "gefühlte" Einschätzung verlassen hatte.

 

## Fazit

 Claude Code auf dem Raspberry Pi funktioniert erstaunlich gut für Home-Automation-Aufgaben. Und ja, ich schulde Claude ein Bier. 🍺

 Das Experiment zeigt: KI-Assistenten sind nicht nur für abstrakte Coding-Aufgaben nützlich, sondern können auch ganz praktische Haushaltsaufgaben übernehmen.
